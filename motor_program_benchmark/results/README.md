# Motor Program Benchmark v1 — reproducible results

These files are generated by `~/tools/CTRNN/motor_program_benchmark/run_mpb_benchmark.m`. The accompanying source is [in the CTRNN repository](/media/Data/OneDrive/tools/CTRNN/motor_program_benchmark/README.md); the methods, equations and figure captions are in [motor_program_benchmark.tex](/media/Data/OneDrive/theory/ActiveAndDeep-theory/Virtuality/motor_program_benchmark.tex).

The full run used GNU Octave 11.1.0 on 23 September 2026: 6 development, 24 evaluation and 12 geometry-transfer layouts. Coordinates are frozen in the code's `layout_manifest.mat` and exported in `layouts.csv`. No parameters are learned. All six hidden rules and sensory outcomes are enumerated exactly. `mixture` means an equal average over the three cue reliabilities; the random-LOOK control matches the active sensing budget across this mixture for each layout. These expectations are not counts of independent sampled trials.

## Files

- `summary.csv` / `summary.json`: aggregate results and numerical validation.
- `layout_metrics.csv` / `route_metrics.csv`: exact means for individual layouts and programs.
- `protocol.json` / `layouts.csv`: executable protocol and all coordinates.
- `cost_sweep.csv`: active and no-epistemic results across LOOK costs.
- `belief_checks.csv`: 126 attention-versus-Bayes comparisons.
- `mpb_report.mat`: complete report, including independent SPM12 posterior checks.
- `mpb_summary_rows.tex` / `mpb_metrics.tex`: generated table rows and verification macros.
- `mpb_benchmark_results.pdf/png`: controls, beliefs and sensing-cost results.
- `mpb_motor_example.pdf/png`: controlled motor traces with program and truth fixed to CBAD.
- `trace_*.csv`: source traces for those controlled examples.
- `sha256_manifest.json`: hashes of the corresponding delivered source and artifact files; paths are relative to the CTRNN benchmark folder.

Both figures are generated by `mpb_plot_results.m`, from the full report. Captions in the LaTeX document link each figure to its equations and producing MATLAB source. Runtime keys, attention and phase-memory interventions affect motor execution only.

## Reproduction

In the CTRNN benchmark folder:

```matlab
report = run_mpb_benchmark();
```

The default performs the verification suite, the full evaluation, and the installed original SPM12 posterior comparison. SPM is an independent static inference reference, not the actor or policy evaluator. See `SPM_REFERENCE.md`. After the run, execute `python3 make_manifest.py` to refresh hashes. To regenerate exports and figures without repeating evaluation:

```matlab
load('results/mpb_report.mat','report');
mpb_write_results(report,'results');
mpb_plot_results(report,'results');
```

Copy the generated results into this directory before rebuilding `virtuality_ctrnn_active_inference.tex`. CSV/JSON sources retain full precision; the LaTeX table rounds only for display. The source is MATLAB-compatible, but this delivered run was verified under Octave, not separately under MATLAB.

## Interpretation

On the evaluation mixture, active sensing succeeds in 86.67% of tasks, compared with 79.44% for random sensing at the same expected LOOK budget. The compiled executor matches the interpreter exactly. Removing the epistemic term gives 80% success with fewer observations and slightly lower pragmatic loss (0.9991 versus 1.0101). The complete objective therefore improves success and decision beliefs without dominating every cost criterion.

This is a finite mechanistic proof of concept, with explicit software planning and hand-designed attention projections. The motor readout issues movement/TOUCH; the planner issues the optional initial LOOK. It does not demonstrate a full neural planner, learned generalization, physical-neuron savings, or superiority on BabyAI/MiniGrid.
