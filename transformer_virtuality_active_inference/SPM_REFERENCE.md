# Independent SPM12 posterior reference

`tva_spm_reference(checks, cfg)` compares the prototype's static three-context posterior updates with the original SPM12 `spm_MDP_VB_X` solver. SPM is an external numerical reference: it does not select the prototype's actions, alter its context beliefs, or supply probabilities to its forward computation.

Each element of `checks` contains:

- `likelihood`: 3×3 matrix, outcome rows and context columns, each column normalized.
- `prior`: positive 3×1 prior (normalized internally).
- `observationindex`: the observed outcome, an integer from 1 through 3.
- `posterioractual`: the prototype's normalized 1×3 posterior, used only after the independent SPM solution for comparison.

```matlab
checks(1).likelihood = [.8 .1 .1; .1 .8 .1; .1 .1 .8];
checks(1).prior = ones(3,1)/3;
checks(1).observationindex = 1;
checks(1).posterioractual = [.8 .1 .1];
info = tva_spm_reference(checks, struct('spm_root', fullfile(getenv('HOME'),'tools','spm12')));
```

For an explicit path use an expanded absolute pathname; MATLAB does not universally expand `~`. Omitting `spm_root` uses `SPM12_ROOT`, or `fullfile(getenv('HOME'),'tools','spm12')` if unset. Missing source files cause an error; the function does not silently skip a requested reference.

The function copies the exact installed bytes of thirteen MATLAB dependencies into a temporary runtime cache. It adds only that directory to the MATLAB path, invokes HMM mode with `T=1`, `tau=1`, one supplied observation, no true hidden state, and no policies/actions, then restores the previous path/RNG state and removes the cache. `tau=1` changes the numerical convergence of this static solver update, not the probabilistic model. The supplied prototype posterior is never passed into the solver.

The returned `info` includes per-check SPM and analytical posteriors, errors against the prototype, overall `maxerror` and `maxanalyticerror`, the original solver pathname, dependency names, and the cache-removal flag. The runtime solver pathname is retained for provenance but is intentionally no longer present after cleanup. A disagreement of SPM with analytical Bayes greater than `1e-10` fails; disagreement with the prototype is reported for the caller to assess.

This reference validates static posterior updates only. It does not validate an entire Transformer architecture, an expected-free-energy policy implementation, or a historical approximate CTRNN interpreter.

## Verification against the task actor

The staged reference was run in Octave 11.1.0 on **72 checks**: both task sensor modes, all three actions, all three outcomes, and four priors (uniform plus all three positive near-point priors with epsilon `1e-9`). The supplied prototype posteriors were generated by the actual `tva_actor`, using `tva_model` likelihoods: the no-op sensor is uniform; the two probes have diagonal reliabilities `.90` and `.55`, exchanged between modes.

The maximum SPM/prototype difference was `1.9984014443252818e-15`; maximum SPM/analytical difference was `2.1094237467877974e-15`. Path/RNG restoration and cache removal passed. A separate controlled check replaced only `posterioractual` with an intentionally wrong distribution: SPM still agreed with analytical Bayes and reported the disagreement, confirming that the supplied posterior is comparison-only. Missing SPM raised the explicit `tva:SPMMissing` error.

`reference_verification.log`, `.json`, and `.mat` record the exhaustive reference comparison. They are verification exports, not inputs to the prototype.
